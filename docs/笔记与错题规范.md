# 笔记与错题规范

> 目的：让 300 天后的自己能在 30 秒内找到「某个知识点的笔记」和「某道题的错因」。

## 一、文件命名

| 类型 | 格式 | 示例 |
| --- | --- | --- |
| 章节笔记 | `<两位章节号>-<标题>.md` | `03-多元函数微分学.md` |
| 专题笔记 | `专题-<标题>.md` | `专题-中值定理构造辅助函数.md` |
| 错题 | `<YYYY-MM-DD>-<来源>-<考点>.md` | `2026-03-15-660题-中值定理.md` |
| 真题 | `<年份>-<科目>-<卷别>.md` | `2024-数学一-真题.md` |
| 周复盘 | `周复盘-<YYYY-Www>.md` | `周复盘-2026-W12.md` |
| 图片 | `<笔记名>-<序号>.png` | `定积分应用-1.png` |

规则：**只用中文、数字、短横线**；不出现空格、括号、`#`、`&`。这样在任何系统、任何链接里都不会出问题。

## 二、Markdown 书写约定

- 一级标题 `#` 只出现一次，写文件标题。
- 重要结论加粗；定理必须写**适用条件**，只写结论的笔记等于没记。
- 公式用 LaTeX：行内 `$f'(x)$`，独立 `$$ \int_a^b f(x)dx $$`。
- 表格用于「对比类」内容（组态对比、易混辨析），列表用于「流程类」内容。
- 图片放进 `assets/<科目>/`，用相对路径引用：`![说明](../../assets/数学/xxx.png)`。

## 三、什么该记，什么不该记

| 该记 ✅ | 不该记 ❌ |
| --- | --- |
| 自己的理解、复述、类比 | 教材原文照抄 |
| 定理的适用条件与反例 | 只有结论没有条件 |
| 解题的「关键转折点」 | 完整抄写标准答案 |
| 易混点的正确区分 | 无差别的知识点罗列 |
| 错因（当时怎么想错的） | 只记正确答案 |

一句话标准：**合上书写不出来，说明这条笔记没价值。**

## 四、错题处理流程

1. **当天入本**：用 `templates/错题模板.md`，保留自己错误过程。
2. **标错因**：从模板的分类中勾选主要 1~2 条。
3. **写转折点**：一句话概括「我当时没想到的那一步」。
4. **一周内重做**：在「复习记录」表里填第二次结果。
5. **两次独立做对** → 标 🟢，避免错题本无限膨胀。
6. **反复错三次以上** → 说明是概念问题，回到对应章节笔记补写「我的理解」。

## 五、标签约定（在错题/笔记正文中写）

```
#极限  #中值定理  #级数  #线性相关  #分布函数
#长难句  #熟词僻义  #翻译技巧
#三极管  #运放  #反馈  #卡诺图  #时序逻辑
#马原  #毛中特  #史纲  #时政
```

## 六、定期维护

- 每周：整理本周新增文件命名、补全错题复习记录、更新对应科目的 `INDEX.md`。
- 每月：用 `git ls-files` 或 GitHub 的文件列表通览一遍，检查是否有命名不合规、放错位置的孤立文件。
- 每阶段结束：写一份 `docs/阶段复盘-<阶段名>.md`，总结该阶段方法与教训。
