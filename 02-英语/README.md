## 二、核心方法（写给自己看的）

- **阅读**：每篇精析必须产出三样东西 —— ①生词 ②长难句拆解 ③每个选项的对错理由（尤其是错项是如何被设计出来的）。
- **单词**：真题里遇到的生词优先级最高；只记「词 + 真题例句 + 熟词僻义」。
- **作文**：不大段背模板，按功能句拆解（开头 / 过渡 / 举例 / 让步 / 结论），每周默写一篇。
