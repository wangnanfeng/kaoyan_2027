# 2027 考研复习笔记

> **仓库定位**：把 2027 考研备考全过程中产出的复习资料、章节笔记、错题复盘、真题记录与阶段总结，按科目分类沉淀到一个可检索、可版本管理的 GitHub 仓库中，让「今天写了什么、哪里还没搞懂、上周错在哪」随时可查、可回溯。
>
> **覆盖科目**：数学、英语、专业课（模拟电子技术基础、数字电子技术基础）、政治。

---

## 一、这个仓库解决什么问题

| 痛点 | 仓库给出的答案 |
| --- | --- |
| 笔记散落在纸质本、Word、平板、聊天记录里 | 全部 Markdown 化，集中在一个仓库 |
| 错题反复错，想不起当时错在哪 | 统一错题模板 + `错题本/` 目录，标签化检索 |
| 复习进度靠感觉，无法复盘 | 各科 `README.md` 内嵌进度表 + `docs/` 阶段复盘 |
| 换设备就找不到资料 | `git clone` 即得全部笔记 |
| 想回看三个月前的思路 | Git 提交历史 + 每次提交写明「章节 + 动作」 |

## 三、命名规范（强制，便于排序与检索）

**笔记文件**：`<章节号>-<标题>.md`

```
01-函数极限连续.md
03-多元函数微分学.md
```

**错题文件**：`<日期>-<来源>-<考点>.md`

```
2026-03-15-660题-中值定理构造辅助函数.md
```

**真题文件**：`<年份>-<科目>-<卷别>.md`

```
2024-数学一-真题.md
2023-模电-期末真题.md
```

**刷题记录**：`<日期>-<题源>-第N章.md`

```
2026-04-02-1000题-第3章.md
```

**图片命名**：`<笔记名>-<序号>.png`，统一存放于 `assets/<科目>/`。

## 四、每天/每周怎么用

```bash
# 1. 开始学习前拉取最新（多设备场景）
git pull

# 2. 新建笔记：从模板复制一份，改名为规范格式
cp templates/笔记模板.md "01-数学/高等数学/05-定积分应用.md"

# 3. 整理错题：从模板复制
cp templates/错题模板.md "01-数学/错题本/2026-03-15-660题-中值定理.md"

# 4. 学习结束提交
git add .
git commit -m "数学/高数: 新增定积分应用笔记 + 3 道错题"
git push
```

**每周日**：用 `templates/周复盘模板.md` 写一篇 `docs/周复盘-YYYY-WW.md`，并刷新各科 `README.md` 里的进度表。

**维护索引**：新增笔记后，手工在对应科目的 `INDEX.md` 补一行链接，并更新根目录 `INDEX.md` 的计数表。若嫌麻烦，直接把各科 `README.md` 当索引用即可。

> **纯 Markdown 原则**：仓库内所有文件都是 `.md`，不引入脚本、不依赖任何工具链，GitHub 网页端就能新增/编辑。
> 图示用 Mermaid 代码块绘制（GitHub 原生渲染），因此连图片都不是必需品：
>
> ```mermaid
> graph LR
>   A[教材/网课] --> B[章节笔记]
>   B --> C[刷题]
>   C -->|做错| D[错题本]
>   D --> E[一周内重做]
>   E -->|再错| B
>   E -->|做对| F[归档]
> ```

## 七、版权与隐私（重要）

- **不要上传**：教材扫描件、机构付费讲义/网课资料、他人未公开的真题解析。这类内容可能涉及版权，且公开仓库会被搜索引擎索引。
- **建议**：若确实需要存放上述资料，把仓库设为 **Private**，或仅保留自己手写的笔记与思路总结。
- **不要写入**：报考院校内部信息、个人联系方式、身份证/学号等隐私内容。
- 引用他人题目时，只记录**题干要点 + 自己的解法与错因**，这是笔记仓库的合理用法。
